  • -Xms和-Xmx

  • -Xms: 设置初始化堆内存大小；

  • -Xmx: 设置最大可分配堆内存大小;

# 初始化128MB 堆内存, 允许最大堆内存最大1024MB. 
java -Xms128m -Xmx1024m
 
# 初始化256MB 堆内存, 允许最大堆内存最大4G.
java -Xms256m -Xmx4g

# jvisualvm插件安装

  • 插件open in new window
  • jvisualvm是我们查看JVM内部结构和JVM调优的重要工具，在java的安装目录的bin目录下。
    • 我们安装的Java默认jvisualvm有很多插件是没有安装的
    • 在bin目录下找到jvisualvm.exe打开，或者在dos窗口执行jvisualvm.
    • 在”工具-插件“之后，选择“设置-编辑”修改url地址为刚刚复制的对应的JDK版本的地址。
