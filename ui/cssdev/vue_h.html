# h()

  • 创建虚拟 DOM 节点 (vnode)。
  • 类型
// 完整参数签名
function h(
  type: string | Component,
  props?: object | null,
  children?: Children | Slot | Slots
): VNode

// 省略 props
function h(type: string | Component, children?: Children | Slot): VNode

type Children = string | number | boolean | VNode | null | Children[]

type Slot = () => Children

type Slots = { [name: string]: Slot }

import { h } from 'vue'

// 除了 type 外，其他参数都是可选的
h('div')
h('div', { id: 'foo' })

// attribute 和 property 都可以用于 prop
// Vue 会自动选择正确的方式来分配它
h('div', { class: 'bar', innerHTML: 'hello' })

// class 与 style 可以像在模板中一样
// 用数组或对象的形式书写
h('div', { class: [foo, { bar }], style: { color: 'red' } })

// 事件监听器应以 onXxx 的形式书写
h('div', { onClick: () => {} })

// children 可以是一个字符串
h('div', { id: 'foo' }, 'hello')

// 没有 prop 时可以省略不写
h('div', 'hello')
h('div', [h('span', 'hello')])

// children 数组可以同时包含 vnode 和字符串
h('div', ['hello', h('span', 'hello')])

# h创建组件

import Foo from './Foo.vue'

// 传递 prop
h(Foo, {
  // 等价于 some-prop="hello"
  someProp: 'hello',
  // 等价于 @update="() => {}"
  onUpdate: () => {}
})

// 传递单个默认插槽
h(Foo, () => 'default slot')

// 传递具名插槽
// 注意，需要使用 `null` 来避免
// 插槽对象被当作是 prop
h(MyComponent, null, {
  default: () => 'default slot',
  foo: () => h('div', 'foo'),
  bar: () => [h('span', 'one'), h('span', 'two')]
})

h 函数是 Vue 3 中用于创建 虚拟 DOM 节点 的核心函数。它是 createElement 的缩写，用于动态生成 Vue 组件的渲染内容。通过学习 h 函数，你可以更好地理解 Vue 的渲染机制，并在需要时动态生成复杂的 UI 结构。

# 1. h 函数的基本用法

h 函数的语法如下：

h(type, props, children);
  • type: 可以是 HTML 标签名（如 'div'）、组件选项对象或异步组件。
  • props: 一个对象，用于传递属性（如 class、style、事件监听器等）。
  • children: 子节点，可以是字符串、数组（包含多个子节点）或其他 h 函数创建的虚拟节点。

# 2. 示例：使用 h 函数创建元素

# 示例 1：创建一个简单的 div 元素

import { h } from 'vue';

const vnode = h('div', { class: 'container' }, 'Hello, Vue!');
  • 生成的虚拟 DOM 相当于：
<div class="container">Hello, Vue!</div>

# 示例 2：创建一个带子元素的 div

import { h } from 'vue';

const vnode = h('div', { class: 'container' }, [
  h('h1', { style: { color: 'red' } }, 'Title'),
  h('p', null, 'This is a paragraph.'),
]);
  • 生成的虚拟 DOM 相当于：
<div class="container">
  <h1 style="color: red;">Title</h1>
  <p>This is a paragraph.</p>
</div>

# 3. 使用 h 函数创建组件

h 函数不仅可以创建 HTML 元素，还可以创建 Vue 组件。

# 示例 3：创建一个 Vue 组件

import { h } from 'vue';

const MyComponent = {
  props: ['message'],
  render() {
    return h('div', { class: 'my-component' }, this.message);
  },
};

const vnode = h(MyComponent, { message: 'Hello from MyComponent!' });
  • 生成的虚拟 DOM 相当于：
<div class="my-component">Hello from MyComponent!</div>

# 4. 动态生成复杂结构

h 函数非常适合动态生成复杂的 UI 结构。例如，根据数据动态生成列表：

# 示例 4：动态生成列表

import { h } from 'vue';

const items = ['Apple', 'Banana', 'Orange'];

const vnode = h(
  'ul',
  null,
  items.map((item) => h('li', null, item))
);
  • 生成的虚拟 DOM 相当于：
<ul>
  <li>Apple</li>
  <li>Banana</li>
  <li>Orange</li>
</ul>

# 5. 在 setup 中使用 h 函数

在 Vue 3 的 setup 函数中，你可以直接使用 h 函数来动态生成内容。

# 示例 5：在 setup 中使用 h 函数

<template>
  <div>
    <render-component />
  </div>
</template>

<script>
import { h } from 'vue';

export default {
  setup() {
    const renderComponent = () =>
      h('div', { class: 'dynamic-content' }, [
        h('h1', null, 'Dynamic Title'),
        h('p', null, 'This is dynamically generated content.'),
      ]);

    return {
      renderComponent,
    };
  },
};
</script>
  • 生成的虚拟 DOM 相当于：
<div class="dynamic-content">
  <h1>Dynamic Title</h1>
  <p>This is dynamically generated content.</p>
</div>

# 6. h 函数的高级用法

# 1. 传递事件监听器

可以通过 props 传递事件监听器：

import { h } from 'vue';

const vnode = h(
  'button',
  {
    onClick: () => alert('Button clicked!'),
  },
  'Click Me'
);
  • 生成的虚拟 DOM 相当于：
<button @click="alert('Button clicked!')">Click Me</button>

# 2. 使用插槽

可以通过 children 传递插槽内容：

import { h } from 'vue';

const MyComponent = {
  render() {
    return h('div', { class: 'my-component' }, this.$slots.default());
  },
};

const vnode = h(MyComponent, null, {
  default: () => h('p', null, 'This is a slot content.'),
});
  • 生成的虚拟 DOM 相当于：
<div class="my-component">
  <p>This is a slot content.</p>
</div>

# 7. h 函数的实际应用场景

  • 动态渲染组件：根据条件动态渲染不同的组件。
  • 高阶组件：通过 h 函数包装组件，实现逻辑复用。
  • 自定义渲染逻辑：在 render 函数中完全控制组件的渲染行为。
  • JSX 的替代方案：如果你不想使用 JSX，可以用 h 函数实现相同的功能。

# 8. h 函数与 JSX 的关系

在 Vue 3 中，JSX 会被编译为 h 函数调用。例如：

const vnode = <div class="container">Hello, Vue!</div>;

会被编译为：

const vnode = h('div', { class: 'container' }, 'Hello, Vue!');

因此，h 函数是 Vue 渲染机制的核心，理解它有助于更好地掌握 Vue 的底层原理。
