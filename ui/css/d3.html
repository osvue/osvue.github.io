在**二维矩阵（二维数组）**上做等高线分析，和常见的科学计算、工程软件（如Matlab、Python的matplotlib、Origin等）里的“等高线图”原理完全一致。

  • https://observablehq.com/plot/marks/auto

# 详细解释

# 1. 数据本质

你定义的 values 实际上是一个二维网格上的标量场，也就是一个 m 行 n 列的矩阵（二维数组），每个点有一个 z 值。

例如，values[y * n + x] 就是第 y 行第 x 列的 z 值。

这和数学上常见的 z = f(x, y) 网格数据完全一致。

# 2. 数学模型

你用的例子：

values.push((x - 0) ** 2 + (y - 50) ** 2);

这就是一个抛物面（paraboloid）模型，z = (x-0)² + (y-50)²。

  • x 取值范围：0 ~ n-1
  • y 取值范围：0 ~ m-1
  • z 是每个 (x, y) 点的函数值

你可以换成任何数学函数，比如：

  • z = sin(x) * cos(y)
  • z = x² + y²
  • z = exp(-((x-40)² + (y-50)²)/100)

# 3. D3 等高线的原理

  • D3 的 d3.contours() 就是对二维矩阵做等值线提取（contour extraction），和科学计算里的 marching squares 算法类似。
  • 你传入的 .size([n, m]) 就是告诉 D3 你的矩阵有 n 列 m 行。
  • thresholds 就是等高线的分割值（等值线的高度）。

# 4. 和矩阵的关系

  • 你可以把 values 看成一个 m×n 的矩阵（二维数组），每个元素是一个 z 值。
  • D3 只要求你把它“拍扁”成一维数组，行优先（row-major）排列即可。

# 5. 和Matlab、Python等的等高线图完全等价

  • Matlab 的 contour(X, Y, Z)，Python 的 plt.contour(X, Y, Z)，Z 就是二维矩阵。
  • D3 的 d3.contours().size([n, m])(values)，values 也是二维矩阵拍扁。

# 总结

  • 你的等高线图就是在二维矩阵（二维数组）上做等值线分析，和科学计算、工程软件的等高线图原理完全一致。
  • 你可以用任何数学模型、仿真数据、实验数据，只要能变成二维数组（矩阵）都可以画等高线。

如需用实际的二维矩阵数据、或者和某个具体数学模型对比， 数据或公式， 转换和可视化

二维矩阵 通过js 可视化

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>D3 等高线色阶图（自定义色带分割值+刻度+坐标轴）</title>
  <script src="https://d3js.org/d3.v7.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/d3-contour@3"></script>
  <style>
    #chart { position: relative; }
    .tooltip {
      position: absolute;
      background: #222;
      color: #fff;
      padding: 6px 10px;
      border-radius: 4px;
      pointer-events: none;
      display: none;
      font-size: 14px;
    }
  </style>
</head>
<body>
<div id="chart"></div>
<script>
// ===================== 基本参数设置 =====================
const margin = { top: 20, right: 60, bottom: 40, left: 50 };
const width = 600;
const height = 300;
const plotWidth = width - margin.left - margin.right;
const plotHeight = height - margin.top - margin.bottom;
const n = 80, m = 100;

// ===================== 构造平滑假数据 =====================
const values = [];
for (let y = 0; y < m; ++y) {
  for (let x = 0; x < n; ++x) {
    values.push((x - 0) ** 2 + (y - 50) ** 2);
  }
}

// ===================== 自定义色带分割值 =====================
const thresholds = [100, 400, 900, 1600, 2500, 3600, 4900, 6400, 8100];

// ===================== 颜色比例尺 =====================
const color = d3.scaleSequential(
  d3.interpolateJet ? d3.interpolateJet : d3.interpolateTurbo
).domain([d3.min(values), d3.max(values)]);

// ===================== 生成等高线数据 =====================
const contours = d3.contours()
  .size([n, m])
  .thresholds(thresholds)
  (values);

// ===================== 创建SVG画布 =====================
const svg = d3.select("#chart")
  .append("svg")
  .attr("width", width)
  .attr("height", height);

// ===================== 坐标缩放函数 =====================
const x = d3.scaleLinear().domain([0, n-1]).range([0, plotWidth]);
const y = d3.scaleLinear().domain([0, m-1]).range([plotHeight, 0]);

// ===================== 主图内容分组 =====================
const plot = svg.append("g")
  .attr("transform", `translate(${margin.left},${margin.top})`);

// ===================== 绘制等高线填充 =====================
plot.append("g")
  .selectAll("path")
  .data(contours)
  .join("path")
  .attr("d", d3.geoPath(d3.geoIdentity().scale(plotWidth/(n-1))))
  .attr("fill", d => color(d.value))
  .attr("stroke", "#fff")
  .attr("stroke-width", 0.5);

// ===================== 绘制色条（colorbar） =====================
// 1. 定义线性渐变
const defs = svg.append("defs");
const linearGradient = defs.append("linearGradient")
  .attr("id", "color-gradient")
  .attr("x1", "0%").attr("y1", "100%")
  .attr("x2", "0%").attr("y2", "0%");

// 2. 渐变色带，0~1线性插值
for (let i = 0; i <= 1; i += 0.01) {
  linearGradient.append("stop")
    .attr("offset", i)
    .attr("stop-color", color(d3.min(values) + i * (d3.max(values) - d3.min(values))));
}

// 3. 绘制色条矩形
svg.append("rect")
  .attr("x", width - margin.right + 20)
  .attr("y", margin.top)
  .attr("width", 20)
  .attr("height", plotHeight)
  .style("fill", "url(#color-gradient)");

// ===================== 绘制色条刻度（与色带边界对齐） =====================
const colorScale = d3.scaleLinear()
  .domain([d3.min(values), d3.max(values)])
  .range([plotHeight, 0]);

const axis = d3.axisRight(colorScale)
  .tickValues(thresholds)
  .tickFormat(d3.format(".0f"));

svg.append("g")
  .attr("transform", `translate(${width - margin.right + 40},${margin.top})`)
  .call(axis);

// ===================== 绘制x轴和y轴（带刻度线） =====================
/*
d3.axisBottom(x)：用 x 缩放函数生成底部坐标轴
d3.axisLeft(y)：用 y 缩放函数生成左侧坐标轴
.ticks(10)：设置刻度数量
.tickFormat(d3.format(".0f"))：刻度显示为整数
轴标签用 text 元素添加，位置和旋转已设置好
*/
// x轴（底部）
svg.append("g")
  .attr("class", "x-axis")
  .attr("transform", `translate(${margin.left},${height - margin.bottom })`)
  .call(d3.axisBottom(x)
    .ticks(10)
    .tickFormat(d3.format(".0f"))
    .tickSize(6)
  );

// y轴（左侧）
svg.append("g")
  .attr("class", "y-axis")
  .attr("transform", `translate(${margin.left},${margin.top})`)
  .call(d3.axisLeft(y).ticks(10).tickFormat(d3.format(".0f")));

// x轴标签
svg.append("text")
  .attr("class", "x-label")
  .attr("x", margin.left + plotWidth / 2)
  .attr("y", height - 5)
  .attr("text-anchor", "middle")
  .attr("font-size", 16)
  .text("X 轴");

// y轴标签
svg.append("text")
  .attr("class", "y-label")
  .attr("x", -margin.top - plotHeight / 2)
  .attr("y", 15)
  .attr("transform", "rotate(-90)")
  .attr("text-anchor", "middle")
  .attr("font-size", 16)
  .text("Y 轴");

// ===================== 鼠标悬停交互（显示x/y/z） =====================
const tooltip = d3.select("#chart").append("div")
  .attr("class", "tooltip");

svg.on("mousemove", function(event) {
  const [mx, my] = d3.pointer(event);
  // 需要减去margin
  const xi = Math.round(x.invert(mx - margin.left));
  const yi = Math.round(y.invert(my - margin.top));
  if (xi >= 0 && xi < n && yi >= 0 && yi < m) {
    const z = values[yi * n + xi];
    tooltip.style("display", "block")
      .style("left", (event.pageX + 10) + "px")
      .style("top", (event.pageY - 20) + "px")
      .html(`x: ${xi}<br>y: ${yi}<br>z: ${z.toFixed(3)}`);
  } else {
    tooltip.style("display", "none");
  }
});
svg.on("mouseleave", () => tooltip.style("display", "none"));

// ===================== 你要显示的点 =====================
/*
points 数组：每个点有 x、y、label 属性，x/y 是数据坐标（不是像素！）。
x(d.x)、y(d.y)：用缩放函数把数据坐标映射到 SVG 像素坐标。
.attr("r", 5)：点的半径。
.attr("fill", "red")：点的颜色。
.attr("stroke", "#fff")：点的边框。
text 标签：给每个点加文字说明。
*/
const points = [
  { x: 20, y: 30, label: "A" },
  { x: 50, y: 50, label: "B" },
  { x: 80, y: 70, label: "C" }
];

// ===================== 在主图上绘制点 =====================
plot.append("g")
  .attr("class", "scatter-points")
  .selectAll("circle")
  .data(points)
  .join("circle")
  .attr("cx", d => x(d.x))
  .attr("cy", d => y(d.y))
  .attr("r", 5)
  .attr("fill", "red")
  .attr("stroke", "#fff")
  .attr("stroke-width", 1.5);

// 可选：加标签
plot.append("g")
  .attr("class", "scatter-labels")
  .selectAll("text")
  .data(points)
  .join("text")
  .attr("x", d => x(d.x) + 8)
  .attr("y", d => y(d.y) + 4)
  .text(d => d.label)
  .attr("font-size", 14)
  .attr("fill", "red");

</script>
</body>
</html>
