# unpkg

如果忽略了文件的路径（例如，使用裸网址 “bare” URL），unpkg会提供 package.json里指定的文件，或降级到main。 unpkg.com/d3

unpkg.com/jquery

unpkg.com/three

这种方式会产生一次 302 到最新的文件URL。好处是自动使用最新版，坏处是多一次性跳转，降低了性能。

在网址最后添加斜线，可以查看一个包内的所有文件列表。

unpkg.com/react/

unpkg.com/lodash/
