# 使用示例

# 要动态生成一个表示“每周二上午 12 点 10 分执行”的 Cron 表达式，可以使用 CronUtils 的 CronBuilder 和 FieldExpressionFactory 来实现。

# 1. Cron 表达式的含义

在 Quartz 格式中，Cron 表达式由以下字段组成：

秒 分 时 日 月 周 [年]

对于“每周二上午 12 点 10 分执行”，对应的字段值如下：

  • 秒：0（表示每分钟的第 0 秒触发）。
  • 分：10（表示每小时的第 10 分钟触发）。
  • 时：12（表示每天的第 12 小时触发，即中午 12 点）。
  • 日：?（不指定具体日期，与“周”字段互斥）。
  • 月：*（表示每月都触发）。
  • 周：3（在 Quartz 中，3 表示星期二，1 表示星期日，7 也表示星期日）。

最终的 Cron 表达式为：

0 10 12 ? * 3

# 2. 动态生成 Cron 表达式的代码

以下是使用 CronUtils 动态生成该 Cron 表达式的完整代码：

import com.cronutils.builder.CronBuilder;
import com.cronutils.model.Cron;
import com.cronutils.model.definition.CronDefinition;
import com.cronutils.model.definition.CronDefinitionBuilder;
import com.cronutils.model.field.expression.FieldExpressionFactory;

public class DynamicCronGeneration {

    public static void main(String[] args) {
        // 定义 Quartz 格式的 Cron
        CronDefinition cronDefinition = CronDefinitionBuilder.instanceDefinitionFor(CronType.QUARTZ);

        // 动态生成 Cron 表达式
        Cron cron = CronBuilder.cron(cronDefinition)
                .withSecond(FieldExpressionFactory.on(0))               // 秒：0
                .withMinute(FieldExpressionFactory.on(10))              // 分：10
                .withHour(FieldExpressionFactory.on(12))                // 时：12（中午 12 点）
                .withDoM(FieldExpressionFactory.questionMark())          // 日：不指定
                .withMonth(FieldExpressionFactory.on("*"))              // 月：每月
                .withDoW(FieldExpressionFactory.on(3))                  // 周：3（星期二）
                .instance();

        // 输出生成的 Cron 表达式
        System.out.println("生成的 Cron 表达式: " + cron.asString());
    }
}

# 3. 运行结果

运行上述代码后，输出的 Cron 表达式为：

生成的 Cron 表达式: 0 10 12 ? * 3

# 4. 代码解析

# (1) 字段设置

  • 秒 (Second)：使用 FieldExpressionFactory.on(0)，表示每分钟的第 0 秒触发。
  • 分 (Minute)：使用 FieldExpressionFactory.on(10)，表示每小时的第 10 分钟触发。
  • 时 (Hour)：使用 FieldExpressionFactory.on(12)，表示每天的第 12 小时（中午 12 点）触发。
  • 日 (DoM)：使用 FieldExpressionFactory.questionMark()，表示不指定具体日期（与“周”字段互斥）。
  • 月 (Month)：使用 FieldExpressionFactory.on("*")，表示每月都触发。
  • 周 (DoW)：使用 FieldExpressionFactory.on(3)，表示每周的星期二触发。

# (2) Quartz 的星期字段规则

在 Quartz 格式中：

  • 1 表示星期日。
  • 2 表示星期一。
  • 3 表示星期二。
  • ...
  • 7 也可以表示星期日。

因此，3 对应星期二。

# 5. 验证生成的 Cron 表达式

为了确保生成的 Cron 表达式正确，可以使用 Quartz 或 CronUtils 验证下一次运行时间。

# 示例代码：验证 Cron 表达式

import com.cronutils.model.Cron;
import com.cronutils.model.definition.CronDefinition;
import com.cronutils.model.definition.CronDefinitionBuilder;
import com.cronutils.model.time.ExecutionTime;
import com.cronutils.parser.CronParser;

import java.time.ZonedDateTime;

public class CronValidation {

    public static void main(String[] args) {
        // 定义 Quartz 格式的 Cron
        CronDefinition cronDefinition = CronDefinitionBuilder.instanceDefinitionFor(CronType.QUARTZ);

        // 创建解析器
        CronParser parser = new CronParser(cronDefinition);

        // 解析 Cron 表达式
        String cronExpression = "0 10 12 ? * 3"; // 每周二上午 12 点 10 分
        Cron cron = parser.parse(cronExpression);

        // 获取执行时间工具
        ExecutionTime executionTime = ExecutionTime.forCron(cron);

        // 当前时间
        ZonedDateTime now = ZonedDateTime.now(); // 替换为你测试的时间，例如 2023-10-09T10:00+08:00

        // 计算下一次运行时间
        ZonedDateTime nextExecution = executionTime.nextExecution(now).orElse(null);
        System.out.println("下一次运行时间: " + nextExecution);
    }
}

运行结果（假设当前时间为 2023-10-09T10:00+08:00）：

下一次运行时间: 2023-10-10T12:10+08:00[Asia/Shanghai]

# 6. 总结

  • 表达式生成：通过 CronBuilder 和 FieldExpressionFactory 动态生成 Cron 表达式。
  • 字段适配性：
    • 使用 on(value) 设置固定值。
    • 使用 questionMark() 表示“不指定”。
  • 验证逻辑：通过 Quartz 或 CronUtils 验证生成的表达式是否符合预期。
